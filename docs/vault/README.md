# SnapGad Content OS — Project Vault

Este directorio es la fuente documental versionada del proyecto. Registra decisiones, estado real, contratos, riesgos y ejecución. No contiene secretos, tokens ni credenciales.

## Cómo usarlo

1. Leer [`00-index.md`](00-index.md) antes de cambiar arquitectura.
2. Actualizar [`01-current-state.md`](01-current-state.md) cuando una funcionalidad pase de demo a staging o producción.
3. Registrar decisiones irreversibles en [`02-decisions.md`](02-decisions.md).
4. Añadir cada cambio relevante a [`03-execution-log.md`](03-execution-log.md).
5. Mantener contratos de datos y límites en [`04-contracts-and-guardrails.md`](04-contracts-and-guardrails.md).

El vault complementa el código: el código es la autoridad de ejecución; el vault es la autoridad de contexto y decisiones.
